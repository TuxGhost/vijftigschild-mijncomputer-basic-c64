# Mijn Computer

Commodore 64 BASIC-programma uit het boek:

***BASIC Computerspellen voor de Commodore 64***
**M.Th.A.M. Vijftigschild – Kluwer**

## Beschrijving

Dit programma is een Commodore 64 BASIC-spel afkomstig uit bovengenoemd boek.

De oorspronkelijke listing is manueel ingevoerd via Visual Code en gecontroleerd op werking op de Commodore 64 / vice emulator.

## Techniek

* **Platform:** Commodore 64
* **Taal:** Commodore BASIC V2
* **Ontwikkelomgeving:** Visual Studio Code
* **Originele bron:** M.Th.A.M. Vijftigschild, *BASIC Computerspellen voor de Commodore 64*, Kluwer

## Uitvoeren

Het programma kan worden uitgevoerd op:

* een originele Commodore 64;
* VICE;
* Commodore 64 Ultimate;
* een andere Commodore 64-emulator.

Het `.bas`-bestand bevat de BASIC-broncode. Indien aanwezig kan het `.prg`-bestand rechtstreeks op een C64 of emulator worden geladen.
